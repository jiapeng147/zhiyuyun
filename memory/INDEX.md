## 脱敏说明

本目录不保存任何秘密值。包括但不限于：

- 登录密码、管理员密码、SSH 密码
- JWT、Cookie、API Key、内部 token
- 数据库 root/app 密码和 Redis 密码
- 第三方网站 token、Cookie 和授权凭证

旧 handoff 文件中曾经存在敏感信息，不能作为凭据来源；需要凭据时只能读取受保护的 `secrets/` 或由用户重新提供。
