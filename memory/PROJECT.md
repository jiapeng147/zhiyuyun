# 项目总览

## 产品定位

智鱼云是面向闲鱼卖家的商业运营工作台，核心目标是把账号、商品、订单、消息、自动发货、卡密、AI 客服和运营设置集中到一个后台。

当前项目是开源闲鱼卖家自动化后台的二次开发版本，产品方向是：

- 商业化、中文化、统一品牌化
- 账号和业务数据隔离
- 真实状态优先，不用伪造套餐、伪造支付或虚假成功状态
- 保留原有业务 API、事件和数据结构
- 前端逐步迁移到统一的商业运营工作台视觉
- 桌面端和移动端 Lite 同时可用

## 已覆盖能力

- 闲鱼账号管理、二维码登录、Cookie 加密存储、状态监控
- 商品同步、商品列表、商品上下架、删除、改价
- 商品发布：单规格、包邮、图片上传、分类级联、AI 描述、AI 分类、位置搜索
- 订单同步和订单状态查看
- 在线消息、会话、消息发送、实时连接
- 自动发货、货源库、发货声明、卡密仓库、发货记录
- 自动回复、AI 客服、知识库和 RAG 检索
- 定时任务、操作日志、反馈建议、通知设置
- 套餐账单、广告申请、商业版桥接
- 系统设置：通用模型、向量模型、RAG、高德地图、通知、平台信息
- 移动端 Lite：首页、消息、自动化、个人中心、商品、账号、数据

## 技术栈

| 层级 | 技术 |
|---|---|
| 后端 | Python 3.11、FastAPI、SQLAlchemy 2 |
| 前端 | Vue 3、Vite、Naive UI |
| Crawler | Node.js 22、TypeScript、Playwright |
| 数据库 | MySQL 8 |
| 缓存 | Redis 7 |
| Web | Nginx SPA |
| 部署 | Docker Compose |

## 目录

```text
apps/api/       FastAPI API、模型、服务、迁移
apps/crawler/   Playwright/滑块求解服务
apps/web/       Vue 前端
deploy/         MySQL 初始化和部署资源
docs/           本地开发、备份恢复、生产准备
scripts/        启动、验证、运维脚本
memory/         本项目接力记忆
docker-compose.yml
```

## 重要产品约束

- 不破坏现有 API、路由 key、事件和业务逻辑。
- 不用“只改颜色”的方式冒充 UI 迁移。
- 页面改造需要保持真实数据状态、错误状态、禁用状态和加载状态。
- 广告和支付没有商业桥接时必须明确不可用，不能展示临时套餐。
- 账号、商品、订单、消息和配置必须遵守用户/租户隔离。
